# Блог Заядлого Путешественника

Трёхстраничный учебный сайт по курсу «Интернет-программирование».
Автор: Махмудолиев Имран Махмудович, группа Бд713.

## Страницы
- `index.html` - главная: пять мест России, карточки на CSS Grid с фотографиями;
- `about.html` - информационная страница: рассказ, советы, таблица «когда ехать», статистика;
- `contact.html` - контакты и форма обратной связи / подписки.

## Что использовано
- modern-normalize.css - сброс стилей браузера по умолчанию, чтобы сайт выглядел одинаково в разных браузерах;
- CSS Grid: разметка страницы, сетка карточек `repeat(auto-fit, minmax(250px, 1fr))`, большие блоки на две колонки, форма;
- адаптивная вёрстка для телефона (`@media`);
- анимация: появление карточек и заголовков (`@keyframes`), пульсирующая кнопка «Наверх», поворот логотипа;
- меню навигации, кнопки перехода, псевдоклассы ссылок, шрифты Google Fonts;
- изображения: фотографии с Wikimedia Commons (авторы указаны на главной странице) и SVG-иконки.
